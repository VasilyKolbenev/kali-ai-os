| Decision | Rationale | Where locked |
|---|---|---|
| **STT stays in Python sidecar** (Phase 3 path B) | `whisper-rs` 0.16 on Windows requires LLVM + CMake + Ninja + a FULL Visual Studio IDE (BuildTools rejected). 4 GB chain per dev machine, same in CI. `faster-whisper` is mature, ~5x faster than reference Whisper, already proven in `kernel/voice/stt.py`. | `kernel/workers/tts_worker.py` `stt_transcribe` op + `src-tauri/src/backend/voice/stt.rs::SttClient` |
| **`ort` 2.x for VAD/wake word** | Default features pull in `download-binaries` → no system OnnxRuntime install needed, no LLVM/CMake. Used cleanly for Silero VAD in Chunk 4. Pattern reused for Chunk 5 wake word. | `src-tauri/Cargo.toml` `ort = "2.0.0-rc.10"` |
| **JSON-stdio bridge primitive** | Spec §7 vindicated by research digest. Not gRPC, not PyO3, not shared memory — `BridgeWorker` with correlation map + writer/reader tasks + `kill_on_drop(true)`. Production-tested across TTS + STT live runs. | `src-tauri/src/backend/voice/bridge.rs` |
| **FD-level stdout redirect in Python ML workers** | Without `os.dup2(2, 1)`, F5/tqdm/HF print spam fills the pipe buffer waiting for `\n` and deadlocks both sides. Discovered live during Chunk 2 debug. | `kernel/workers/tts_worker.py` top-of-module |
| **Project-local `HF_HOME`** | The user's global `C:\Users\User\.cache\huggingface\` had `WinError 183` permission breakage from a prior interrupted download. `HF_HOME = repo/.hf_cache` set BEFORE any HF import sidesteps the global cache entirely. | `kernel/workers/tts_worker.py` top-of-module |
| **`ort` ndarray version must match exactly** | Different ndarray majors are different types per cargo. `Tensor::from_array` only impls `OwnedTensorArrayData<T>` for the version `ort` itself uses. Pinned `ndarray = "0.17"` to match `ort 2.0.0-rc.12`. | `src-tauri/Cargo.toml` |

### Known gotchas (carry-forward — read before touching ML)

All seven traps in `memory/feedback_ml_build_friction.md`. Highlights:

1. **`whisper-rs` is OFF the table on Windows** until `prebuilt` feature ships or VS install becomes acceptable. `ort` is the path for Rust-native ML.
2. **Python ML workers MUST redirect FD 1 to FD 2** at module top via `os.dup`/`os.dup2`. JSON envelope writes via `os.write(_BRIDGE_FD, ...)`. Without this, tqdm progress bars deadlock the bridge.
3. **Force `HF_HOME` before any HF-using import.** `setdefault` is a footgun. Use direct assignment.
4. **`ort` ndarray version must match.** Check `cargo tree -p ort | grep ndarray` and pin to that major.
5. **`ort::Error` is not `std::error::Error`** in 2.x rc → use `.map_err(|e| anyhow!(...))` not `.context(...)`.
6. **Naive 3:2 decimation of 24 kHz F5 → 16 kHz produces aliasing** that breaks Whisper STT and Silero VAD. In tests, route through scipy server-side. In production, cpal will be 16 kHz native — no resample needed.
7. **`cargo test ... | tail -N` reports tail's exit code, not cargo's.** Don't trust exit 0 on a piped cargo test. Capture full output to a file instead.

Plus the prior list (CSS var suffix, .venv breakage, uv vs pytest, etc. — see `2026-04-24-phase-2-closed-tier1-5of7.md`).

## Key Patterns Discovered

### PyInstaller gotchas
- `--onefile` + multiprocessing = fork bomb unless `freeze_support()` is FIRST LINE
- `sys.executable` in frozen mode = `kali-backend.exe` — so `subprocess.Popen([sys.executable, agent.py])` spawns full backend copies (disaster). Use in-process protocol instead.
- Premium backend > 2GB breaks NSIS mmap — use 7z SFX (`7z.sfx + config + .7z` concatenated)

### ElevenLabs voice cloning
- Requires **Creator subscription** on ElevenCreative tab (NOT Pay-as-you-go credits on ElevenAPI tab — common confusion)
- API key permissions: `voices_read`, `voices_write`, `text_to_speech` minimum
- Cyrillic filenames in multipart upload cause `invalid_audio` error — use ASCII names
- Reference clips must be 16-bit PCM mono WAV (transcode via soundfile)

### Agent Skills spec
- YAML frontmatter fields: `name` (required), `description` (required), `license`, `compatibility`, `metadata`, `allowed-tools`
- Name must match parent directory name
- Body is markdown instructions for LLM (not code)
- Scripts in `scripts/` subdir optional, safety-gated at install

### RTX 5070 (Blackwell) specific
- Compute capability `sm_120` — requires torch+cu128 (not cu124)
- `uv.lock` has custom index: `[tool.uv.sources] torch = [{ index = "pytorch-cu128" }]`
- torchcodec needs FFmpeg SHARED build (from BtbN/FFmpeg-Builds, not Gyan static) — DLLs in `models/ffmpeg/`

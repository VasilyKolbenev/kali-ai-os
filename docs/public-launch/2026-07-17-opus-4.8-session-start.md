## ОТДЕЛЬНЫЙ TTS PERFORMANCE TRACK — НЕ СМЕШИВАТЬ С RELEASE P0

Текущий русский F5 голос является quality baseline и остаётся fallback, пока кандидат не победил в одинаковом слепом сравнении. Не заменяй движок только по чужому benchmark и не начинай обучение до измерения.

Фактический baseline на этой RTX 5070 Laptop:

- current engine: F5TTS_v1_Base Russian accent checkpoint, Vocos, NFE16, CFG2;
- quality-gate NFE16: median synthesis около 1729 мс, mean RTF около 0.61, CER 0.1526, SIM 0.6240;
- NFE7: около 1010 мс и RTF 0.384, но SIM упал примерно на 0.026 — отклонено по тембру;
- отдельный sprint measurement: short first chunk около 0.8–1.2 с, perceived full-pipeline TTFA около 2.8 с;
- reference audio длится 9.62 с;
- reference preprocessing уже кешируется, поэтому повторять «просто закешировать WAV» бессмысленно;
- F5 package в venv = 1.1.17, latest upstream = 1.1.21; upgrade сам по себе не обещает latency gain;
- реальный EPSS уже включён upstream по умолчанию, поэтому NFE7 experiment был EPSS, а не обычным uniform 7-step.

### Сначала измерить

Расширь benchmark, не меняя production default:

1. Отдельно измерить text normalization/RUAccent, prompt/reference prep, DiT/ODE, vocoder, first PCM, queue и actual speaker playback.
2. Метрики: cold load, warm TTFA до первого PCM и до первого звука, full synthesis, RTF, peak VRAM/RAM, installer delta.
3. Добавить NFE10/12/14 к существующим NFE7/16/32. Сейчас промежуточная зона не проверена.
4. Проверить CFG0 только как эксперимент: он убирает cond/uncond branch и потенциально почти удваивает DiT speed, но требует строгого voice-quality gate.
5. Проверить legally clean reference длиной 3–5 с против 9.62 с. Короткий reference может снизить DiT sequence cost; кеш I/O этого не делает.
6. Проверить KALI_TTS_FIRST_CLAUSE=1 и шов слепым ухом, но не включать default автоматически.
7. Проверить, действительно ли LLM streaming, synthesis следующего chunk и playback работают параллельно, а не блокируют друг друга через awaited callback.

### Controlled bake-off кандидатов

Каждый кандидат запускается в отдельном disposable environment/process. Не добавляй dependencies в основной bundle до выбора победителя.

1. F5 NFE16 — текущий quality baseline.
2. F5 custom checkpoint через официальный Triton/TensorRT-LLM runtime — лучший шанс сохранить голос без смены модели. Upstream показывает около 253 мс average latency на L20 при NFE16 против PyTorch RTF 0.1467, но custom Russian checkpoint и Windows/RTX 5070 должны быть проверены локально.
3. Qwen3-TTS-12Hz-0.6B-Base — главный replacement candidate: Apache-2.0, русский, 3-second voice cloning, reusable prompt, text/audio streaming. Заявленные 97 мс не считать нашей метрикой до локального Windows test.
4. Fun-CosyVoice3-0.5B-2512 — второй candidate: Apache-2.0, русский, zero-shot cloning, bi-streaming, заявлено до 150 мс. Учесть package около 9.75 GB и открытые reports о Russian/first-chunk regressions.
5. Chatterbox Multilingual V3 — quality/control candidate: MIT, русский, 500M, zero-shot cloning. Не считать cloud service latency показателем local model.

VibeVoice не брать в основной shortlist: официальный repository удалял TTS code и сам не рекомендует commercial/real-world deployment без дополнительной проверки; voice customization ограничена.

Официальные источники:

- F5 current runtime/benchmark/license: https://github.com/SWivid/F5-TTS
- Fast F5 EPSS paper: https://arxiv.org/abs/2505.19931
- IntMeanFlow few-step distillation: https://arxiv.org/abs/2510.07979
- Qwen3-TTS: https://github.com/QwenLM/Qwen3-TTS
- Qwen3-TTS 0.6B Base model/license: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base
- CosyVoice3: https://github.com/FunAudioLLM/CosyVoice
- Chatterbox Multilingual: https://github.com/resemble-ai/chatterbox

### Единый gate для всех движков

Используй существующие 25 frozen RU phrases, добавь отдельный holdout corpus и одинаковые seed/reference/text-normalization.

Hard gates:

- warm first audible chunk <=500–700 мс на RTX 5070 Laptop;
- warm RTF <=0.30 для средней фразы;
- speaker SIM не хуже current F5 NFE16 более чем на 0.02;
- CER не хуже baseline более чем на 0.5 процентного пункта;
- нет обрезки, повторов, hallucinated speech и неверных ударений;
- владелец не предпочитает baseline в blind A/B;
- peak VRAM укладывается в 8 GB вместе с нужными runtime components;
- offline clean bundle без runtime downloads;
- коммерчески совместимые code, weights, reference voice и training data.

Official benchmark numbers разных авторов не сравнивать напрямую: решение принимается только на одной машине и нашем русском corpus.

### Дистилляция F5 — только если bake-off не дал победителя

Не дистиллировать текущий Misha/F5 CC-BY-NC checkpoint для коммерческого релиза: distillation не снимает ограничение teacher weights/training provenance.

Допустимый путь:

1. Legally clean F5 teacher/base и собственный русский voice dataset с consent.
2. Progressive trajectory/consistency distillation 16 → 8 → 4/3 NFE, предпочтительно IntMeanFlow-подобный подход.
3. Сохранение голоса через speaker-verification cosine loss.
4. Сохранение разборчивости через ASR/CTC loss.
5. Mel/STFT, duration, F0/energy/prosody losses.
6. Финальный frozen-corpus gate и blind A/B владельца.

Это отдельный R&D sprint, а не быстрый prod-ready fix.

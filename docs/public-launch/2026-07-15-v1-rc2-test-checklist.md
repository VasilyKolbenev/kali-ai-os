# KALI 1.0.0-rc2 — чеклист живого тестирования (Vasily)

**Артефакт:** `dist_premium\installer\KALI-Premium-Setup-1.0.0-rc2.exe` + **3 файла `.bin` рядом** (всего 4.40 GB). При переносе/раздаче копировать ВСЕ 4 файла — без любого `.bin` установка сломается; для друзей паковать в один zip.

**Что нового против rc1:** auto-update (баннер + скачивание + тихая установка) · crash opt-in (промпт при смерти ядра) · main.py распилен на роутеры (поведение должно быть идентичным — если что-то в чате/навыках отвалилось, это регрессия распила, скажи).

**Уже проверено машиной (2026-07-15):**
- Сборка: бэкенд 5.83 GB (LGPL-swap 23 действия) → `kali-desktop.exe` 39.6 MB → инсталятор 4 файла
- Тихая установка в чистую папку → **приложение само поднялось** (это новая `.iss`-строка для auto-update, отработала впервые)
- В установленной копии живы новые роуты: `/updater/status` → `current: 1.0.0-rc2`, `/crash/status` → `backend_alive: true`
- `frozen_smoke` (health/whisper/f5/reel/gpl) — см. итог в конце сессии

**Что может проверить только человек:** звук ушами, микрофон, UX-ощущения, телефон, время секундомером, **и глазами — что в crash-отчёте нет секретов**.

## 0. Подготовка (2 мин)

- [ ] Закрой мою тестовую копию: в трее/диспетчере убей `kali-desktop.exe` и `kali-backend.exe` (она стоит в `C:\kali-rc2-test` — ставилась для машинного гейта, без ярлыков)
- [ ] Удали `C:\kali-rc2-test` (чтобы не путаться с настоящей установкой)
- [ ] **Ставь как друг:** двойной клик по `KALI-Premium-Setup-1.0.0-rc2.exe` (обычный мастер, папка по умолчанию, галочки ярлыков)

## A. Установка и первый запуск (~10 мин)

- [ ] SmartScreen покажет «неизвестный издатель» — ожидаемо до EV-cert: Подробнее → Выполнить в любом случае
- [ ] Мастер проходит, ярлык на рабочем столе, KALI запускается
- [ ] Онбординг: API-ключ (или skip → потом честный RU-CTA в чате) → модели → mic-test
- [ ] Шаг «Расскажи о себе» (анкета): имя + пол (+город); проверь 🎤-кнопку у поля; «Пропустить» тоже должен работать

## B. Голос — главное (~10 мин)

- [ ] Спроси голосом что-нибудь простое. **Секундомер: конец твоей речи → первый звук.** Ожидание после прогрева ~2–3 с (первый запрос дольше — холодный старт)
- [ ] **Ухо: тембр Джарвиса не изменился** (дефолт NFE16). Слышишь деградацию → env `KALI_F5_NFE=32` + перезапуск (откат без пересборки)
- [ ] Пауза в середине фразы («эээ… подумать») — не обрезает ли 900мс-окно? Раздражает → `KALI_SILENCE_MS=1500` (или 2500 = старое)
- [ ] Анкета-грамматика: если указан пол «женский» — «ты уверена?»-класс согласований

## C. Crash opt-in — НОВОЕ (~5 мин)

- [ ] При работающем UI убей **`kali-backend.exe`** в диспетчере (именно бэкенд, не десктоп)
- [ ] Через **~15 с** внизу справа появляется промпт «Похоже, ядро аварийно остановилось» *(15 с — это 3 проба подряд по 5 с, чтобы не дёргать тебя на мигании сети)*
- [ ] **До клика ничего не собирается** — это opt-in по дизайну
- [ ] Клик «Подготовить отчёт» → показывает путь к `crash-<дата>.txt` + свёрнутое превью «Что внутри»
- [ ] «Открыть папку» реально открывает проводник на файле; «Копировать» кладёт текст в буфер
- [ ] 🔴 **ГЛАВНОЕ — открой .txt и прочитай глазами:** нет ли твоего имени пользователя в путях, API-ключей, токенов, email. **Редакция — defense-in-depth, а НЕ гарантия: ты, читающий файл перед отправкой, и есть финальный гейт.** Утекло что-то → пришли строку, добавлю паттерн
- [ ] Полезность: понятно ли из отчёта, ПОЧЕМУ упало? (там хвосты трёх логов: stderr + собственный лог Python + stdout)

## D. Auto-update — НОВОЕ, частично (~2 мин)

- [ ] Баннера обновления быть НЕ должно — манифест ещё не опубликован, апдейтер тихо молчит (это правильное поведение, а не поломка)
- [ ] **Полная репетиция обновления возможна только с rc3:** установленная rc2 → публикуем rc3 → у тебя всплывает баннер → скачивание 4.2 GB → тихая установка → перезапуск. Это отдельный сеанс, скажешь когда

- [ ] Телефон (standalone): `kali://import` шаринг-ссылки на ДРУГОМ устройстве без десктопа → агент работает; напоминалка стреляет при убитом приложении

- [ ] Чат/навыки в целом — регрессия после распила main.py на роутеры (эндпоинты те же, но проверь на глаз)

## Известные штуки (не баги, не пугайся)

- **`/health` показывает `1.0.0-rc1`, а апдейтер — `1.0.0-rc2`.** Нашёл живой проверкой: версия живёт в 5 местах, я бампнул 3 (Rust/инсталятор), а Python-сторона (`kernel/__init__.py`, `pyproject.toml`) осталась. **Косметика:** обновление и crash-отчёт берут версию из Rust, так что работают верно. Чиню в исходниках + расширяю проверку до всех 5 — rc3 приедет консистентным
- SmartScreen ругается — до EV-сертификата это нормально
- Crash-промпт поллит бэкенд каждые 5 с — в логах будут строки `/health`, это ожидаемо

## Откаты, если что-то раздражает

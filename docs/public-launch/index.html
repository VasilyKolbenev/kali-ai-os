Что делает KALIWhat it does

Не «ещё один чат-бот». KALI превращает твою идею в настоящего агента, который выполняет задачи — и живёт на твоём устройстве.

Создаёшь голосом

«Считай кирпичи по фото и напоминай про смену» — и через минуту агент у тебя в кармане. Без кода и настроек. Describe it out loud; a working agent appears in about a minute — no coding.

Работает на твоём железе

Голос (JARVIS) синтезируется локально на твоей видеокарте NVIDIA. Разговоры и факты лежат в локальной базе на твоём диске. Voice runs locally on your NVIDIA GPU; your data stays in a local database on your disk.

Делишься, как видео

Записал результат — поделился через обычное системное «Поделиться». Друг открывает ссылку и ставит того же агента себе. Share via the normal OS share sheet — no platform login. A friend taps the link and installs the same agent.

Спрашивает разрешение

Прежде чем агент получит доступ к календарю, почте или сообщениям — KALI понятным языком спрашивает, что именно разрешить. Before an agent touches your calendar, mail, or messages, KALI asks in plain language.

Помнит и напоминает

Утренняя сводка, погода, задачи, расходы, регулярные напоминания — агенты работают по расписанию, пока ты занят делом. Morning brief, weather, tasks, reminders — agents run on schedule while you work.

Открытый формат

Агенты — это файлы SKILL.md по открытому стандарту Anthropic. Созданное в KALI переносимо, а не заперто в одном приложении. Agents are open SKILL.md files — portable, not locked to one app.

Твои данные остаются у тебяYour data stays with you

Приватность — не галочка в настройках, а то, как KALI устроен. По умолчанию всё локально.

  • Локальный голос на твоей видеокарте Синтез речи JARVIS работает на твоём GPU. Без облака для голоса — если у тебя есть видеокарта NVIDIA. JARVIS voice synthesis runs on your own GPU — no cloud needed for speech.
  • Разговоры — в локальной базе История и факты хранятся в базе на твоём диске, а не на наших серверах. Conversations and facts live in a local database on your disk, not our servers.
  • Ключи API — только у тебя Если подключаешь облачную модель, ключ лежит в локальном файле на твоём ПК и никуда не уходит. If you connect a cloud model, your API key stays in a local file on your machine.
  • Песочница для каждого агента Агент видит только свою папку, ходит в сеть лишь на разрешённые домены, а опасный код блокируется до запуска. Each agent is sandboxed: own folder, allow-listed network, dangerous code blocked before it runs.
  • Без OAuth соцсетей для шеринга Делишься через стандартное системное «Поделиться» — мы не просим вход в TikTok, Instagram или другие платформы. Sharing uses the native OS share sheet — we never ask for a social-platform login.

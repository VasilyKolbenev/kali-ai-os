**Что уже проверено машиной (2026-07-13):** silent-установка в чистую директорию → бут установленной копии → smoke ALL PASS (health `1.0.0-rc1` · Whisper cuda/float16 · F5-синтез · reel MP4 · av.libs без GPL + LGPL-лицензия вложена). Тестовая установка удалена — ставишь начисто.
**Что может проверить только человек:** звук ушами, микрофон, UX-ощущения, телефон, время секундомером.

## A. Установка и первый запуск (~10 мин)
- [ ] Запусти инсталятор обычным способом (SmartScreen покажет «неизвестный издатель» — ожидаемо до EV-cert: Подробнее → Выполнить в любом случае)
- [ ] Установка завершается, ярлык на рабочем столе, KALI запускается
- [ ] Онбординг: API-ключ (или skip → потом честный RU-CTA в чате) → модели → mic-test
- [ ] **НОВОЕ — шаг «Расскажи о себе» (анкета)**: заполни имя + пол (+город) — проверь и 🎤-кнопку у поля, если STT уже готов; «Пропустить» тоже должен работать

## B. Голос (главное, ~10 мин)
- [ ] Спроси голосом что-нибудь простое. **Секундомер: конец твоей речи → первый звук.** Ожидание после прогрева: ~2–3 с (первый запрос дольше — холодный старт). До спринта было 8–15 с
- [ ] **Ухо: тембр Джарвиса не изменился** (дефолт теперь NFE16 — гейт+моё сравнение прошли, финальное слово за тобой). Если слышишь деградацию: env `KALI_F5_NFE=32` и перезапуск — откат без пересборки
- [ ] Пауза в середине фразы («эээ... подумать») — не обрезает ли теперь 900мс-окно? Если обрезает раздражающе: `KALI_SILENCE_MS=1500` (или 2500 = старое)
- [ ] Анкета-грамматика: если указан пол «женский» — «ты уверена?»-класс согласований в ответах
- [ ] Опционально: `KALI_TTS_FIRST_CLAUSE=1` → ещё быстрее первый звук; слушай ШОВ после первой клаузы («Конечно, | сэр...») — реши, жить ли флагу

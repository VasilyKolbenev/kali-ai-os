**Источники:** ultracode-воркфлоу `wf_bde035ac-aaf` (17 агентов: 4 аудита кода + 6 web-research + адверсариальная верификация + синтез) + **живой замер на RTX 5070 Laptop 8GB** (этой машине).
**Binding constraint (Vasily):** F5 = якорь качества (голос Джарвиса). Движок НЕ меняем без quality-equal аналога — ускоряем саму F5 + перекрываем стадии пайплайна. Цель: конец речи → первый звук **< 1 с локально**.

## 1. Живой замер (прогретая F5, NFE=32, CFG=2.0, fp16, ref 9.62с)

| Фраза | Аудио | Синтез (тёплый) | RTF |
|---|---|---|---|
| «Да, сэр.» (короткая) | 0.53 с | **~3.5 с** | 6.4–7.1 |
| Средняя (вопрос о погоде) | 3.2 с | ~6.0–6.9 с | 1.8–2.1 |
| Длинная (2 предложения) | 7.6 с | ~6.7–7.3 с | **0.88–0.96** |

Холодный первый синтез: 15–28 с (CUDA-warmup) — в проде скрыт prewarm'ом. `load_models` с кэшем: мгновенно (lazy).

**Ключевой вывод замера:** фикс-стоимость **~3.3 с на вызов** доминирует (короткая фраза = почти чистый оверхед); маржинальная стоимость ~0.5 с за секунду аудио. Причина в том, что 9.62-секундный референс-WAV прогоняется через пайплайн **на каждом вызове** (torchaudio.load с диска + mel + DiT-последовательность в основном состоит из референса — для короткой фразы >90% вычислений уходит на референс). Опубликованные RTF 0.12–0.15 — это desktop 3090; ноутбучная 5070 в ~15 раз медленнее заявленных бенчей. **«<1 с» на текущем сетапе не достигается ни одним изменением в одиночку — нужна комбинация.**

## 2. Карта пайплайна (аудит, десктоп local-путь) — где лежат секунды

Последовательно, без перекрытий: **2.5 с тишины** (KALI_SILENCE_MS, `pipeline.py:137,299`) → **STT полного буфера, блокирует event loop** (`pipeline.py:328`, beam=5) → memory-контекст await (`:439`) → **LLM НЕ-стриминговый** `route()` (`:452`; `route_streaming`+`SentenceBuffer` уже написаны и работают в remote-пайплайне, но в local НЕ подключены; стриминг вообще реализован только для openai — Anthropic/Google/local ждут полного ответа, `llm_router.py:356`) → **memory-экстракция awaited ДО TTS** (`:456` — потенциально целый лишний LLM round-trip; remote делает её ПОСЛЕ) → синтез 1-го предложения F5 (~3.5–7 с, см. замер) → звук.

Итого сегодняшний TTFA ≈ 2.5 + STT + LLM(полный) + memory + 3.5–7 с ≈ **8–15+ с**.

## 4. Ранжированные атаки (синтез, скорректирован живым замером)

1. **Хирургия пайплайна** (silence 900 + stream-LLM→TTS в local + Anthropic-стриминг + memory в bg + STT-твики) — **−4–6 с**, ноль ML-риска, 2–3 дня.
2. **F5 fixed-cost pack:** кэш/укорочение референса + show_info + f5-tts upgrade + короткий первый чанк — бьёт прямо в измеренные 3.3 с фикс-стоимости.
3. **EPSS-7 / NFE-16** на RU-чекпоинте — 2–4× на DiT; вместе с (2) короткий первый чанк потенциально ~0.5–1 с.
4. **RU-квалити-гейт СНАЧАЛА** (ворота для 2, 3 и всего дальнейшего): замороженный сет 20–30 RU-фраз → ΔCER (ASR round-trip) + ECAPA speaker-sim (drop ≤0.02) + ΔUTMOS ≥ −0.1 + слепой A/B при жёлтой зоне; переиспользовать eval-харнесс из репо F5. 1–2 дня, потом ~10 мин/эксперимент.
5. **Дистилляция — фаза 2**, только если 1–4 не дают <1 с или гейт заваливает EPSS. Облако, $50–300 скоуп.

**Реалистичная арифметика после 1+2+3:** тишина 0.9 + STT ~0.3 + LLM-первое-предложение ~0.5–1.0 (стрим) + F5-первый-чанк ~0.5–1.0 = **~2.2–3.2 с воспринимаемо** (сегодня 8–15 с). Честно: «<1 с» от конца речи чисто арифметически упирается в silence-окно + LLM; «<1 с» от конца *тишины* — достижимо с (3). Формулировку цели стоит уточнить на brainstorm.

## Приложение: методология замера
`scripts/measure_voice_latency.py` (P0) устарел: меряет холодный первый синтез, STT-стадию моделью «base» (в проде «small»; на этой машине залипла патологически на CPU-пути — убита), константа silence 700 вместо реальных 2500. Тёплый замер — scratchpad `measure_warm.py` (load → warmup discard → 3×short/3×med/2×long). Перед стартом работ: обновить P0-скрипт (warmup + first-chunk + реальные константы) — он же станет базой квалити-гейта.

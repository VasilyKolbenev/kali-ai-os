# Spec: Voice-latency Sprint 1 — «прогретый Джарвис отвечает за ~2 секунды»

**Date:** 2026-07-12 · **Status:** DRAFT (ждёт утверждения Vasily)
**Grounding:** `docs/superpowers/specs/2026-07-12-f5-latency-grounding.md` (17-агентный воркфлоу + живой замер на RTX 5070 Laptop).
**Constraint (binding):** F5 = якорь качества; движок не меняем; каждое ускорение проходит RU-квалити-гейт; local остаётся приватным.

## Решения brainstorm (Vasily, 2026-07-12)
- **Скоуп:** все 4 атаки одним спринтом (гейт → хирургия → F5-pack → EPSS). Дистилляция = фаза 2, только если не хватит.
- **Окно тишины:** 2500 → **900 мс** (env-дефолт; откат одной переменной, если вернутся обрывы «на подумать»).
- **LLM-провайдер прода = OpenAI** → стриминг уже реализован; Anthropic-стриминг НЕ в этом спринте (follow-up для BYO-key пользователей).
- **Короткий первый чанк:** да, за флагом, финальный гейт = ухо Vasily (отключаем, если шов слышен).

## Цель и метрика
**Метрика: perceived TTFA = конец речи → первый звук из колонок** (desktop local-путь, прогретые модели), измеряется обновлённым P0-скриптом. Baseline сегодня: ~8–15 с.
**Target: ≤ 3 с. Stretch: ≤ 2 с.** (Арифметика: 0.9 тишина + ~0.3 STT + ~0.5–1.0 LLM-первое-предложение стримом + ~0.5–1.0 F5-первый-чанк после EPSS+кэша.)
Квалити-инвариант: ΔCER ≤ +0.5 п.п., ECAPA speaker-sim drop ≤ 0.02, ΔUTMOS ≥ −0.1, финально — ухо Vasily (слепой A/B при жёлтой зоне).

## Инкременты (порядок исполнения)

### A. Квалити-гейт + честный замер (ворота для всего остального)
1. Обновить `scripts/measure_voice_latency.py`: warmup-синтез перед замером, прогретые 3×short/3×med/2×long, тайминг первого чанка, реальные конфиг-константы (silence из env, STT-модель из конфига), per-stage сводка.
2. Новый `scripts/tts_quality_gate.py`: замороженный сет 20–30 RU-фраз (числа, имена, вопросы, «сэр») → синтез кандидат-конфигом → ΔCER через существующий faster-whisper + ECAPA cosine SIM к референсу + UTMOS; выход = PASS/WARN/FAIL таблица. WARN → слепой A/B для Vasily.
3. Зафиксировать baseline-отчёт (текущий конфиг) — точка сравнения всех экспериментов.

### B. Хирургия пайплайна (desktop `kernel/voice/pipeline.py`)
1. `KALI_SILENCE_MS` дефолт 2500 → 900 (+ конфиг-комментарий про откат).
2. Memory-экстракция: awaited → `asyncio.create_task` ПОСЛЕ TTS (паттерн remote_pipeline:247).
3. Prefetch `get_user_context_string()` параллельно STT (`asyncio.gather`).
4. STT: `asyncio.to_thread` (сейчас блокирует event loop) + `beam_size` 5→2 (гейт: WER на RU-командном сете из A).
5. **Портировать `route_streaming` + `SentenceBuffer` в local-путь** (паттерн remote_pipeline:203): LLM стримит → предложения уходят в F5 по мере готовности → первый звук не ждёт хвост ответа. Tool-call ходы честно фолбэчатся на нестрим (как в remote).

### C. F5 fixed-cost pack (`kernel/voice/tts_engine_f5.py`)
Бьёт в измеренные ~3.3 с оверхеда на вызов:
1. Кэш референса: убрать per-call `torchaudio.load` 9.6с-WAV (прекомпьют тензора/мела один раз при load_models; если API F5 не позволяет — вклиниться на уровне utils_infer).
2. `show_info=None` / убрать tqdm+print из горячего пути.
3. Апгрейд `f5-tts` до ≥1.1.19 (кэш vocos MelSpectrogram/resamplers) — проверить changelog-выигрыш замером.
4. Эксперимент за гейтом: укороченный референс (9.6с → ~5с) — только если SIM-гейт PASS + ухо.
5. Короткий первый чанк за флагом `KALI_TTS_FIRST_CLAUSE=1`: первая клауза (до запятой/тире, ≥N символов) отдельным синтезом + cross-fade ~0.15 с остальным — ухо-гейт.

### D. EPSS-7 / NFE-редукция (`tts_engine_f5.py` сэмплер)
1. Кастомное расписание таймстепов {0,2,4,6,8,16,24,32}/32 (EPSS-7, arXiv 2505.19931) — вклинить в вызов сэмплера (~5–20 строк; upstream не смержил).
2. Fallback-ступень: `NFE_STEP` 32→16 (одна строка), если EPSS на RU-чекпоинте заваливает гейт.
3. Обе конфигурации через квалити-гейт из A + финальное ухо Vasily.
4. НЕ в скоупе: cfg_strength=0 (высокий риск тембра — отдельный эксперимент по желанию), torch.compile (опциональный замер, на bs=1 бывает регресс), TRT-LLM (баг конверсии RU-чекпоинта #1188).

## Вне скоупа спринта
Дистилляция (фаза 2 — свой brainstorm при недоборе цели) · Anthropic/Google-стриминг (follow-up) · Rust Gate A секвенирование (отдельное решение: Rust-путь сейчас регрессит sentence-streaming) · mobile/remote-путь (уже стримит) · изменение голоса/референса без ушного гейта.

## Тесты
- A: гейт-скрипт юнит (метрики на фикстурах, PASS/WARN/FAIL пороги); замер-скрипт smoke (запускается, печатает стадии).
- B: silence-константа из env; memory-экстракция не awaited до TTS (тест: TTS стартует до завершения extraction-мока); prefetch параллелен (порядок вызовов); local-путь получает предложения из SentenceBuffer до конца LLM-стрима (мок-стрим).
- C: ref-кэш — один load на N синтезов (счётчик-мок); первый-чанк флаг: split-логика клауз + cross-fade длина.
- D: расписание таймстепов передаётся в сэмплер (мок), NFE из env.
- Гейты репо: `pytest -m core_loop` + kernel-suite; финал — живой прогон: голосовой вопрос → секундомер TTFA + ухо.

## Results (2026-07-12, спринт закрыт)

**Замеры на RTX 5070 Laptop 8GB (прогретые медианы, `measure_voice_latency.py`):**

| Метрика | До спринта | После | Δ |
|---|---|---|---|
| Окно тишины | 2500 мс | 900 мс | −1600 мс |
| F5 short-чанк («Да, сэр.») | 1877 мс | **813 мс** (RTF 1.52) | 2.3× |
| F5 med-предложение | 3111 мс | **1482 мс** (RTF 0.46) | 2.1× |
| F5 long | 3887 мс | 1896 мс (RTF 0.25) | 2.0× |
| LLM | полный ответ до TTS (3174 мс замер) | стримится, TTS с 1-го предложения | — |
| **Perceived TTFA (оценка)** | **~8–15 с** | **~2.8 с** (0.9 тишина + ~0.3 STT + ~0.8 LLM-1е-предл + 0.81 TTS) | **~4×** |

**Квалити-гейт (сидированный, `2026-07-12-tts-gate-seeded.json`):** NFE16 — SIM 0.624 vs 0.625 (идентичен), ΔCER +0.58 п.п. (вся дельта в 1 фразе из 25), **ухо Vasily: «голос тот же» → принят дефолтом**. NFE7 — ОТКЛОНЁН (SIM −0.026, тембр). Все флаги откатываемы: `KALI_SILENCE_MS`, `KALI_STT_BEAM`, `KALI_F5_NFE`, `KALI_F5_CFG`, `KALI_TTS_FIRST_CLAUSE` (выкл. по умолчанию, ждёт ушной проверки шва в живом использовании).

**Честные заметки:** кэш референса выигрыша по времени не дал (фикс-стоимость = DiT-вычисления над 9.6с референс-последовательностью, не I/O) — но fast-path дал env-ручки и контроль чанкинга. Несидированный гейт показал ±2 п.п. CER-шума на идентичных конфигах → сид обязателен (встроен в гейт). Финальная верификация DoD = живой голосовой тест Vasily (секундомер+ухо). Дистилляция (фаза 2) не понадобилась для цели ≤3 с.

## Definition of Done
1. Обновлённый P0-замер показывает TTFA ≤ 3 с (прогретый, десктоп, RTX 5070 Laptop) на med-фразе.
2. Квалити-гейт PASS на выбранной конфигурации (EPSS-7 или NFE-16) + Vasily подтвердил ухом «голос тот же».
3. Все флаги откатываемы env-переменными без пересборки.
4. Baseline/after-отчёты приложены к спринту; методология воспроизводима одним скриптом.

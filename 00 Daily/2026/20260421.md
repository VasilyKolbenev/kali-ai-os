# 2026-04-21

## Session Log — 20:00 (Release 0.2.0-beta)

**Focus:** Завершение стратегического pivot на Agent Skills spec + выпуск
v0.2.0-beta с полной инфраструктурой (каталог, publish, sandbox, audit UI).

### Context
Accumulated work across 6 strategic phases (started 2026-04-17):
- Phase 1-3: SKILL.md foundation + multi-source catalog
- Phase 4-5: Agent Store UI + publish flow
- Phase 6: Sandbox hardening (enforcer + rate limiter + audit)

Today: finish monitoring UI + HTTP client sandbox + release.

### Completed
- **A. VISION.md promoted to v0.5.0** — Phase 5 & 6 marked DONE, added Stats
  section (141 tests, 15 skills, 4 sources, 2 TTS engines, 2 installers),
  added 7th differentiator (sandbox transparency)
- **B. SandboxActivity UI mode** (new sidebar item ⬢) — fetches `/sandbox/audit`
  and `/sandbox/stats`, shows:
  - 4 summary cards: Total / OK / Denied / Errors
  - Per-agent usage bars (ok/denied/error proportions)
  - Recent dispatches feed with icons, duration, denial reasons
  - Filters: 1h / 24h / 7d / 30d × All / OK / Denied / Error
- **C. SandboxHttpClient** (`kernel/sandbox/http_client.py`) — preferred HTTP
  client for skill scripts:
  - Domain whitelist from manifest permissions
  - Rate limiting per agent
  - 30s timeout cap, 10MB response size cap
  - Typed exceptions (DomainBlockedError / RateLimitError / SandboxHttpError)
  - Wildcard subdomain matching (`*.example.com`)
  - Audit sink integration (+17 tests)
- **D. Both installers rebuilt with v0.2.0-beta:**
  - KALI-Lite-Setup-0.2.0-beta.exe — 104 MB (NSIS, Telegram-ready)
  - KALI-Premium-Setup-0.2.0-beta.exe — 3.4 GB (7z SFX, GDrive)
  - Added skills + sandbox modules to PyInstaller hidden imports
- **E. Release 0.2.0-beta:**
  - CHANGELOG.md created following Keep-a-Changelog format
  - `pyproject.toml` + `kernel/__init__.py` → 0.2.0-beta
  - Git tag `v0.2.0-beta` pushed to origin/kali-ai-os

### Decisions Made
| Decision | Rationale |
|----------|-----------|
| Network Proxy: opt-in HTTP client, NOT monkey-patch | Thread-unsafe global patching breaks caller expectations; opt-in wrapper cleaner |
| Activity as separate sidebar mode | Full-screen canvas needed for audit feed; cleaner than cramming into Settings |
| Skip Ollama local LLM for MVP | Adds 2-4 GB to installer; defer to Phase 7 behind feature flag |
| Version scheme: 0.2.0-beta (not 0.5.0) | CHANGELOG semver-tracks; 0.5.0 in VISION.md is roadmap milestone |

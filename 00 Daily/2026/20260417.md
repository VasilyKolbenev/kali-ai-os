**Focus:** Major TTS stack migration — replaced Silero+RVC with F5-TTS (GPU) + ElevenLabs cloud cloning for JARVIS voice. Built Lite installer for friends distribution.

- **Critical fix: fork bomb** — `multiprocessing.freeze_support()` moved to dedicated `entry.py` BEFORE any imports
- **In-process agent protocol** — new `InProcessProtocol` replaces subprocess-based for frozen bundles (prevents `sys.executable=kali-backend.exe` spawn loop)
- **Unified JARVIS persona** — `kernel/jarvis_persona.py` used by both LLMRouter and `/chat`
- **Multi-provider AgentBuilder** — supports OpenAI, Anthropic, Google, DeepSeek (was hardcoded Claude)
- **Intent Classifier LLM mode** + regex fallback
- **Deployer rollback** on skill/agent deployment failures
- **Anti-echo buffer 500ms** — mic restarts after TTS with delay to prevent self-recording

### Decisions Made
| Decision | Rationale |
|----------|-----------|
| F5-TTS over Silero+RVC | Russian + English in one model, 3x better quality, voice clone from reference |
| ElevenLabs as CPU fallback | Voice clone 95% quality, works without GPU (will replace with own GPU server later) |
| Two-installer strategy (Lite/Premium) | Lite 104MB for friends via Telegram; Premium 4GB for GPU users via Google Drive |
| Creator plan $22/mo over Starter $5 | Commercial license + 100k chars/mo for future monetization |
| In-process agents in frozen mode | Only way to avoid fork bomb with PyInstaller's sys.executable |
| Voice `auto_start: false` default | Privacy + RAM — user opts into always-listening mode |

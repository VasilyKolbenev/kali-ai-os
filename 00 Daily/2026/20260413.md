### Decisions Made
| Decision | Rationale |
|----------|-----------|
| Skills (YAML) + Agents (code) dual model | Users create simple things without code risk; complex things with LLM + sandbox |
| NemoClaw-inspired sandbox via JSON-RPC | Subprocess agents can't import requests/urllib; all HTTP through kernel proxy |
| Permission-based (not strict sandbox) | Like smartphone permissions — user approves per agent |
| Cloud Catalog on Supabase | PostgreSQL + Auth + Storage, free tier sufficient for MVP |
| Karpathy coding rules as default | Prevents LLM overengineering — simplicity first, surgical changes |
| DirectML over CUDA for RVC | No CUDA toolkit needed on Windows, RTX 5070 works with DirectML |

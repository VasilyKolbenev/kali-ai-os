### Decisions Made
| Decision | Rationale |
|----------|-----------|
| Python + FastAPI kernel, Tauri + React UI | Python for AI/ML ecosystem, Tauri for lightweight native desktop |
| Microkernel architecture with Event Bus | Isolated agents, extensible, hardware-ready |
| Hybrid LLM (Claude/OpenAI + Ollama local) | Best quality online, offline fallback |
| JSON-RPC for native agent protocol | Simple, fast, language-agnostic subprocess IPC |
| Google Calendar with local JSON fallback | Works with or without Google account |
| No-Code Agent Builder with templates | Killer feature for community — anyone can create agents |
| OpenAI support alongside Anthropic | User choice — use whatever API key you have |
| ESP32-S3 as thin WiFi client, not standalone | Too weak for Python/LLM, perfect as remote display+mic |

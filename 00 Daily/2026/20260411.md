### ONNX Pipeline Progress
- test_ONNX_FINAL.wav — первый рабочий вариант (HuBERT + pyin F0 + RVC), ~80% похожести
- test_ONNX_FAISS.wav — добавлен FAISS index blending (rate=0.8), ~90% похожести
- Осталось ~10% — решение: переобучить на чистом Sound Pack
- Ключевые находки при ONNX миграции:
  - HuBERT output нужен `np.repeat(hubert, 2, axis=2).transpose(0, 2, 1)` (RVC_Onnx_Infer repo)
  - Pitch: f0_mel encoding `1127 * log(1 + f/700)` → scale 1-255 (НЕ raw Hz!)
  - Audio загружается в SR модели (40000), HuBERT input ресемплится в 16000
  - FAISS index: `make_direct_map()` + `reconstruct()` для извлечения векторов
  - `librosa.pyin` для F0 на Windows (pyworld не компилируется)

### Decisions
| Decision | Rationale |
|----------|-----------|
| Silero+RVC=финальный голос | Одобрен test_SILERO_RVC.wav |
| ONNX вместо PyTorch RVC | Убирает fairseq/WSL, нативный Windows |
| dynamo=False + legacy exporter | Новый exporter несовместим с RVC |
| dynamic_axes в ONNX | Fixed size → chunking → артефакты |
| Прямой OpenAI в /chat | voice_pipeline._llm нестабилен |
| Sound Pack вместо Remaster | 54 чистых оригинала vs 25 битых ремастеров |

# Web Surfer

Этот агент выступает в роли "умного браузера". Используй его, когда пользователь просит найти информацию в интернете, сравнить цены, прочитать статью по ссылке или провести исследование.

## Script
Для поиска информации и парсинга сайтов используй скрипт `scripts/surf.py`.
Скрипт принимает аргументы командной строки для выполнения поиска или чтения конкретного URL.

Пример использования:
```bash
python scripts/surf.py --search "купить iPhone 15 Pro цена"
python scripts/surf.py --url "https://example.com"
```

Текущая задача: масштабное мануальное тестирование обеих версий приложений (Desktop и Mobile) вместе с бэкендом. 

**Для запуска среды необходимо:**
1. Перезапустить старый бэкенд: `uv run python run_server.py`
2. Узнать локальный IPv4 адрес компьютера (`ipconfig`).
3. Запустить десктоп: `cd ui && pnpm tauri dev`
4. Сбросить кэш мобилки: `cd mobile && flutter clean && flutter pub get`
5. Запустить мобильное приложение на эмуляторе/устройстве и ввести IP компьютера.

**Фокус тестирования:**
- Зависания, краши и неожиданное поведение интерфейса.
- Найденные остатки хардкода.
